# API Keys API

## 2026-09-25

### Feature

The API Keys remote Model Context Protocol (MCP) server is available in
[Preview](https://cloud.google.com/products#product-launch-stages). You can
connect to the API Keys remote MCP server from AI applications to
create, inspect, restrict, and manage the lifecycle of API keys in your
Google Cloud projects.

For more information, see the
[API Keys MCP reference](https://docs.cloud.google.com/api-keys/docs/reference/mcp).
