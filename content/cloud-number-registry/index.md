# Cloud Number Registry

## 2026-09-16

### Breaking

You must [designate a project to manage
Cloud Number Registry](https://docs.cloud.google.com/number-registry/designate-project-cloud-number-registry)
before you can [set up
Cloud Number Registry](https://docs.cloud.google.com/number-registry/set-up-cloud-number-registry)
for an organization.

---
## 2026-04-22

### Announcement

**Preview**: [Cloud Number Registry](https://docs.cloud.google.com/number-registry/overview)
provides IP address management (IPAM) capabilities to let you view, manage, and
plan your IP address usage in Google Cloud.
