# Cloud Tasks

## 2026-07-21

### Feature

Cloud Tasks support for the following is available in
[Preview](https://cloud.google.com/products#product-launch-stages):

* [Set retry parameters when creating a task](https://docs.cloud.google.com/tasks/docs/configure-retry-task)
  and override the queue-level retry configuration for the task.
* [Create a batch of tasks](https://docs.cloud.google.com/tasks/docs/create-tasks#create-batch-tasks)
  and add the batch to an existing queue.
* [Delete a batch of tasks](https://docs.cloud.google.com/tasks/docs/manage-queues-and-tasks#delete-batch-tasks)
  from a queue.
